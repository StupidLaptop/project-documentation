# Agent role guides

This folder holds short prompts that help an agent resume a documentation role after conversation context is cleared. A role guide is not a requirement, decision, approval, or replacement for the root [AGENTS.md](../AGENTS.md).

- [Product Steward](product-steward.md) — a copyable, project-neutral startup prompt.

Tailor a copied prompt to the project's name and approval roles. Keep changing project facts in the governed documentation, not in role prompts.
