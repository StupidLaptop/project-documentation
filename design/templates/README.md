# Design templates

Copy these files into a feature proposal or approved design directory; never treat the templates themselves as reviewed designs.

- [design-brief.md](design-brief.md) — problem, audience, states, constraints, and open questions.
- [design-review.md](design-review.md) — reviewer findings, evidence, decisions, and approvals.
- [design-contract.md](design-contract.md) — versioned approved interaction and presentation contract.
