# Design editing instructions

Read the root `AGENTS.md` first. Start feature design from an approved handoff and accepted decisions. Keep source mockups and research in `reference/`; they do not authorize behaviour. Write proposals in `proposals/` with a stable feature ID and explicit open questions. Record review evidence and named approvals before promoting a versioned contract to `approved/`; update the handoff to link that contract. Do not assume a particular component library, theme, framework, or device unless the project has approved one.
