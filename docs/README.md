# Canonical project documentation

This area separates original evidence from maintained project intent.

| Folder | What belongs here | Authority |
| --- | --- | --- |
| [source/](source/README.md) | Supplied documents, dated baselines, provenance | Evidence; preserve unchanged |
| [requirements/](requirements/README.md) | Approved, stable-ID obligations | Canonical once approved |
| [workflows/](workflows/README.md) | User and operational journeys, state changes, exceptions | Canonical when approved |
| [schema/](schema/README.md) | Conceptual entities, relationships, data rules | Canonical where a decision or requirement confirms it |
| [roadmap/](roadmap/README.md) | Epics, dependencies, waves, gates, milestones | Derived planning view |
| [traceability/](traceability/README.md) | ID allocation, source mapping, change effects | Audit and navigation view |
| [templates/](templates/README.md) | Blank source, requirement, epic, and traceability formats | Examples only |

Accepted decisions may clarify these documents. If a source and a maintained file conflict, record the conflict and the decision that resolves it.
