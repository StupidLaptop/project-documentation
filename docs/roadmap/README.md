# Roadmap

Keep the macro plan here: epic index, dependency graph, suggested delivery sequence, thin end-to-end milestone, open decision gates, and links to detailed epic files. The roadmap is a derived planning view. It does not approve a feature or override a requirement.

Use [epics/](epics/README.md) for one file per coherent epic. Distinguish a hard prerequisite from a preferred sequence, and update the graph when an accepted change alters dependencies. Avoid dates or commitments unless an owner has approved them.
