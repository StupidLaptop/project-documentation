# Epic files

An epic is a capability boundary large enough to show dependencies and outcome, but small enough to guide feature slicing. Copy [the epic template](../../templates/epic.md) for a new epic. Link requirements, prerequisite epics, open decision gates, and a thin milestone where applicable. Do not turn an epic file into a detailed implementation ticket.
