# Traceability

Use this area to answer: where did a rule come from, what decision changed it, which epic and feature own it, and where was it verified? Keep a requirement allocation index and a change log here. Prefer stable IDs and links over copied paragraphs.

Before issuing IDs, define this project's prefixes and rules below. Never recycle an ID after publication.

| Record type | Prefix and format | Owner |
| --- | --- | --- |
| Requirement | To define | To define |
| Change request | To define | To define |
| Decision | To define | To define |
| Epic | To define | To define |
| Feature | To define | To define |

Suggested files: `requirement-allocation.md`, `change-log.md`, and `source-map.md`. Create them when real records exist. Start from the [allocation](../templates/requirement-allocation.md) and [change-log](../templates/change-log.md) templates.
