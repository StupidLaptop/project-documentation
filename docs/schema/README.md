# Conceptual schema

Describe entities or information objects, relationships, identifiers, ownership, lifecycle, important constraints, retention, and historical meaning. This area expresses product and data intent; it does not require a relational database or prescribe a storage design. Link confirmed rules to requirements and decisions, and label proposed structures clearly.

Group files by domain. When a relationship or state is undecided, record the alternatives and blocking question instead of choosing a table shape by convenience.
