# Planning templates

Copy these files for a real feature and replace every placeholder. They establish a consistent review shape, not project requirements.

- [feature-handoff.md](feature-handoff.md) — bounded outcome and product contract.
- [implementation-plan.md](implementation-plan.md) — delivery approach and verification, usually maintained by the delivery team.
- [review.md](review.md) — independent findings and acceptance reconciliation.
