# Decision records

Use a decision record when a choice changes product meaning, data handling, security, operations, architecture, or more than one feature. Copy [ADR-template.md](ADR-template.md), assign the next stable ID, and add the record to an index here once a real decision exists.

Statuses: **Proposed**, **Accepted**, **Rejected**, or **Superseded**. Only an accepted record resolves an open question. Keep rejected and superseded records so future readers understand what was considered. A new decision should name any earlier record it amends or supersedes and link to affected requirements and handoffs.
