# Change inbox

The inbox receives new requests, review findings, stakeholder comments, and other evidence. Nothing here changes approved behaviour merely by being filed.

| Folder | Meaning | Next step |
| --- | --- | --- |
| [new/](new/README.md) | Received and unassessed | Assign an ID, source, and triage owner |
| [triaged/](triaged/README.md) | Impact and dependencies assessed | Decide, seek clarification, reject, or incorporate |
| [incorporated/](incorporated/README.md) | Outcome reflected in authoritative files | Keep the original and links to the result |
| [templates/](templates/README.md) | Reusable intake forms | Copy; never edit a template as a request |

Retain withdrawn, rejected, and superseded requests with their outcome. The inbox is a history of incoming change, not a second requirements catalogue.
