# Project context

Put short orientation documents here: purpose and boundaries, actors, domain vocabulary, important invariants, and a navigable list of open questions. These files help a new reader choose which detailed documents to open. They should point to sources and decisions rather than repeat a full specification.

Suggested files are `product-overview.md`, `domain-glossary.md`, `core-invariants.md`, `roles-and-responsibilities.md`, and `open-questions.md`. Create only the files the project needs. Label uncertain statements and include a stable question ID where an answer blocks work.
